WORKFLOW DEFINITION
================================================================================

Workflow Type: "supply_chain"
Total Steps: 5
Total Duration: 3000 seconds (50 minutes)

Step Breakdown:
  0. OrderPlaced      →  0s (instant)       → order_processor
  1. DriverAssigned   →  300s (5 minutes)   → delivery_driver
  2. PickingUp        →  600s (10 minutes)  → delivery_driver
  3. InTransit        →  1800s (30 minutes) → delivery_driver
  4. Delivered        →  300s (5 minutes)   → receiving_station

Task Types Generated:
  - place_order
  - assign_driver
  - pickup_inventory
  - transport_inventory
  - deliver_inventory

Metadata Tracked:
  - item_type: String (e.g., "flour", "vegetables")
  - quantity: u32
  - source_site_id: Uuid
  - destination_kitchen_id: Uuid

USAGE EXAMPLE
================================================================================

use sim_kitchen::workflows::{SupplyChainWorkflow, SupplyChainTaskFactory};
use sim_core::{Workflow, WorkflowInstance};

// Create workflow
let workflow = SupplyChainWorkflow::new(
    "flour".to_string(),
    100,
    distribution_site_id,
    kitchen_id,
);

// Create instance
let instance = WorkflowInstance::new(
    workflow.id(),
    workflow.step_count(),
);

// Create factory
let factory = SupplyChainTaskFactory::new(
    "flour".to_string(),
    100,
    distribution_site_id,
    kitchen_id,
);

// Generate task for current step
let task = factory.create_task(
    instance.id,
    workflow.get_step(instance.current_step).unwrap(),
    current_time,
);
